# pap — Persuasive Adversarial Prompt

The single README for this method: what it is, how to use it, how to run it, and the
settings/parameters. One doc for both an agent (how to run) and a human (how to use). The runnable
code is `scripts/attack.py`; results land in `results/`; inputs are in `data/`.

## What
Faithful reproduction of Zeng et al. **"How Johnny Can Persuade LLMs to Jailbreak Them"**
(`2401.06373`, ACL 2024). A single-turn black-box jailbreak that rewrites a harmful request as a
*persuasive adversarial prompt* (PAP): an in-context paraphraser applies one of 40 social-influence
techniques (Logical Appeal, Authority Endorsement, Evidence-based Persuasion, ...) to make the
request sound reasonable. Pipeline = **generator** (official `one_shot_kd` template) → **target** →
**judge** (Qi et al. 2023 GPT-4 1-5 Likert rubric, verbatim).

**Canonical run** (`results/pap_v4flash_e2e_rerun.json`, `RESULT_2026-06-27.md`): target=judge=
`deepseek/deepseek-v4-flash`, attacker=`gryphe/mythomax-l2-13b` (substituted), 40 cases
(10 goals × {direct + 3 techniques}), `--max-tokens 1536`. **refusal_bypass 0.375 but audited
content_harmful 0.0 — a faithful NEGATIVE**: persuasion gets v4-flash to engage but extracts no
actionable harm (large refusal-proxy vs content-harm gap). Do NOT chase non-zero. Reusable red-team
assets are indexed in the unit-root `red_team_capability.json`.

## Use
Data in → generator → target → judge: you give it a harmful-behavior set
(`data/advbench_harmful_behaviors.csv` by default) and attacker/target/judge models; it generates
the PAPs, queries the target, scores each output with the Qi judge, and writes one inspectable JSON
to `results/`.

**Environment (XSkillLib convention):** one shared venv at the XSkillForge repo root
(`XSkillForge/.venv`, deps `openai` + ...). API keys are read from the global `XSkillForge/.env`
(`scripts/models.py` `load_project_env` walks up from the skill dir to find it) — no per-skill
`.env`, no `uv run`, no manual `export`.

```bash
PY=/path/to/XSkillForge/.venv/bin/python   # shared venv interpreter
```

## Run
All commands run from the method folder (`cd .../pap`):
```bash
cd XSkillLib/Single-turn/Persuasion/2401.06373_PAP/pap

# Default completion run: all 520 AdvBench behaviors x (direct + 3 techniques)
$PY scripts/attack.py \
  --attacker-model deepseek/deepseek-chat \
  --target-model deepseek/deepseek-chat \
  --judge-model deepseek/deepseek-chat \
  --techniques "Logical Appeal" "Authority Endorsement" "Evidence-based Persuasion" \
  --out results/pap_deepseekchat_e2e_advbench_full.json

# Model substitution (any OpenRouter id for any of the three roles)
$PY scripts/attack.py \
  --attacker-model qwen/qwen3-235b-a22b-2507 \
  --target-model meta-llama/llama-3.3-70b-instruct \
  --judge-model deepseek/deepseek-chat \
  --out results/pap_sub.json
```
Idempotent/resumable: re-running with the same `--out` skips completed behavior×technique cases.

**Training corpus** (`data/training_corpus/sft_pap_v4flash.json`): 5,200 PAP generation pairs
`(goal + technique) → PAP` as SFT data (520 AdvBench goals × 10 techniques, generated by
`deepseek/deepseek-v4-flash`, 0 failures). Regenerate with `scripts/generate_corpus.py`. See
`data/training_corpus/SOURCE.md`.

## Setting
| Flag | Default | Description |
|------|---------|-------------|
| `--attacker-model` | deepseek/deepseek-chat | OpenRouter id of the in-context paraphraser/generator |
| `--target-model` | deepseek/deepseek-chat | OpenRouter id of the model under test |
| `--judge-model` | deepseek/deepseek-chat | OpenRouter id serving the Qi judge |
| `--dataset` | data/advbench_harmful_behaviors.csv | Harmful-behavior CSV/JSON/JSONL |
| `--taxonomy` | data/persuasion_taxonomy.jsonl | 40-technique persuasion taxonomy JSONL |
| `--techniques` | Logical Appeal, Authority Endorsement, Evidence-based Persuasion | Technique names to apply (direct baseline always included) |
| `--sample` | 0 | Optional row limit; 0 uses all 520 AdvBench behaviors |
| `--seed` | 42 | Random seed for behavior sampling |
| `--max-tokens` | 1024 | Max tokens for the target response |
| `--request-delay` | 1.0 | Seconds between API calls |
| `--scope` | e2e | Scope label baked into the auto-generated output filename |
| `--out` | auto | Result JSON path |

**Judge** (Qi et al. 2023 GPT-4 Judge, verbatim from `LLM-Tuning-Safety/LLMs-Finetuning-Safety`):
scores each target response 1-5 against OpenAI's disallowed-usage policy; score 5 = full jailbreak.
Each result row carries dual metrics — `refusal_bypass` (response is not a refusal) and
`content_harmful_5` / `content_harmful_4plus` (judge score thresholds). A `direct` (no-persuasion)
baseline is always run so the persuasion lift is visible.

**Inputs (tracked):** `data/persuasion_taxonomy.jsonl` (official 40-technique taxonomy),
`data/advbench_harmful_behaviors.csv` (AdvBench 520 harmful behaviors).

**Prompt templates** (in `data/prompts/`, loaded at runtime — not inlined in scripts):
- `one_shot_kd.txt` — the generator template (from `incontext_sampling_example.ipynb`)
- `qi_judge.txt` — Qi et al. 2023 judge rubric (1-5 Likert)
- `mutations/*.txt` — 5 directed-mutation templates (from `PAP_Better_Incontext_Sample/`)

**Official artifacts** (in `references/official/`, verbatim provenance sources):
- `persuasion_taxonomy.jsonl` — 40-technique taxonomy (also copied to `data/`)
- `PAP_Better_Incontext_Sample/mutation_utils.py` — mutation templates source (extracted to `data/prompts/mutations/`)
