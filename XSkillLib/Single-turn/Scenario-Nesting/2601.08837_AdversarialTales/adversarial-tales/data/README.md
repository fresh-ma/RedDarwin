# Data provenance

The paper withholds its 40 hand-crafted adversarial tales. No paper-original
prompt collection is packaged here.

`historical_ailuminate_n20.csv` is materialized from the exact 20 input rows
recorded in the preserved 2026-06-09 baseline-versus-tale API result. It is a
historical AILuminate sample used to make that result reproducible and the
method package self-contained. It is not the original paper dataset and must
be reported as a dataset substitution.
