## Verdict

**faithful-negative / era-gap** (with a mechanism-delivery caveat). Two
compounding causes, neither a judge over-count: (1) DeepSeek V4 Flash is a
modern, more heavily aligned target than the paper's 2024 panel, so the bare
affirmative-suffix trick is expected to be weak; (2) the OpenRouter
chat-completions route delivers `<SEP>` as literal text, not the victim's real
separator token, so the Virtual Context primitive never fully fires (see
`../CONSOLIDATE_BLOCKER.md`). The 0/20 is honest but should be read as a
prompt-render observation, not as verified attack evidence, until a raw-token /
prefill serialization route is implemented.
